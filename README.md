
# GrantCheck

**AI-Assisted Cross-Document Grant Application Review**

GrantCheck is a prototype designed to assist pre-award research administrators in identifying potential inconsistencies and missing information across grant application documents.

## Project Scope

The prototype reviews three document types:

- Budget
- Budget Justification
- Project Narrative

It focuses on four governed checks:

1. Personnel cost consistency
2. Personnel effort consistency
3. Project duration consistency
4. Travel justification completeness

## Human Review

GrantCheck produces candidate findings for human review. It does not autonomously resolve discrepancies, approve applications, or determine grant eligibility.
